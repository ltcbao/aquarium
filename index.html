Deploy on Cloudflare Pages or Netlify

Zero-build static hosting • 100% client-side persistent state

AquaVerse is architected as a self-contained single-file web application (index.html) with automatic localStorage state persistence and portable JSON Save Export/Import.

Option 1: Cloudflare Pages
  1. Save this file as index.html inside a folder.
  2. Open Cloudflare Dashboard → Compute (Workers & Pages) → Pages.
  3. Choose "Upload assets" (Direct Upload) or connect a Git repo.
  4. Drag & drop the folder. Build command: None. Output directory: /.
Option 2: Netlify Drop
  1. Save this file as index.html inside an empty folder.
  2. Visit app.netlify.com/drop in your browser.
  3. Drag the folder onto the dropzone for an instant live HTTPS URL.
  4. Players' aquariums auto-save locally in their browser and can be backed up via JSON.
